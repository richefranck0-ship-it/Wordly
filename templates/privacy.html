Politique de confidentialité

Modèle à adapter à votre situation (RGPD) et à faire relire.

Données traitées

  • Visites : compteurs anonymes par jour (pas d'identifiant personnel). Un cookie technique d'une journée distingue les visiteurs uniques.
  • Notifications : si vous les activez, nous enregistrons l'adresse technique d'abonnement de votre navigateur, vos catégories, votre langue et, si vous l'avez choisi, la ville pour les alertes météo.
  • Traduction : le texte est transmis au prestataire de traduction pour être traduit ; il n'est pas conservé par WORLDLY. L'historique reste dans votre navigateur.
  • Météo et position : la position n'est utilisée qu'avec votre autorisation, directement par votre navigateur auprès d'Open-Meteo.
  • Formulaires (contact, publicité) : nom, e-mail et message pour traiter votre demande.

Vos droits

Accès, rectification, suppression : contactez-nous. Vous pouvez effacer les données locales depuis les paramètres de confidentialité.
